Sampling Statistics Research Methods

Sampling 101

14 มีนาคม 2026 · อ่านประมาณ 8 นาที

Probability Sampling — การสุ่มแบบมีความน่าจะเป็น

กลุ่มวิธีการสุ่มที่ทุกคนใน Population มีโอกาสถูกเลือกอย่างที่กำหนดได้ ผลที่ได้จึงสามารถ represent ไปถึง population ได้

Simple Random Sampling

จาก population ทั้งหมดจะมีโอกาสในการถูกสุ่มเท่ากันทุกคน ถ้า pop = 100 โอกาสที่จะถูกสุ่มก็คือ 0.01 ตัวอย่างง่ายๆ ก็เช่น การซื้อหวย

การทำ Simple random sampling จะทำได้ดีในระบบปิด ตัวอย่างเช่น ใน community ต่างๆ ที่มีสมาชิกชัดเจน หรือในบริษัท

Systematic Random Sampling

มีระบบหรือเงื่อนไขบางอย่างที่ช่วยในการสุ่มตัวอย่าง

เริ่มจากการที่เราสุ่มข้อมูลที่เรามีก่อน จากนั้นเราจะเลือกคนแรกแล้วเว้น 2 คน แล้วค่อยเลือกคนถัดไป — แบบ 1 ข้าม 2 เหมือนเป็นการ set rule base ในการหา sample

Cluster Random Sampling

เริ่มจากการแบ่งข้อมูลออกเป็น 3 กลุ่ม แล้วเราจะสุ่มจากกลุ่ม ได้กลุ่มไหนเราก็จะเลือกกลุ่มนั้นมาเป็น sample เช่น เราแบ่งรายชื่อนักเรียนออกเป็น 3 กลุ่ม เราก็จะสุ่มกลุ่มนักเรียน 1 กลุ่ม

  • แต่ละกลุ่ม (cluster) ควรจะมีจำนวนเท่ากัน
  • การแบ่งกลุ่มทำได้หลายทาง ไม่ว่าจะเป็นการสุ่ม หรือการแบ่งจาก demographic บางอย่าง เช่น เพศ อายุ หรือแบ่งจาก character บางอย่าง (e.g. spending) หรือจะไม่แบ่งจากอะไรเลยก็ได้
  • กระบวนการนี้จะเหมาะกับคนที่ไม่มีเวลา ฉะนั้นวิธีนี้ก็จะไม่ accurate เท่าไหร่

Stratified Random Sampling

เรียกว่าเป็น Market research 101 เลยก็ว่าได้

ตัวอย่าง: เราอยากเก็บ sample 1,000 คน (n = 1,000) ในประเทศไทย

  • Step 1 — แบ่งตามภูมิภาค: เริ่มจากการแบ่งเป็นภาคๆ ก่อน เหนือ, อีสาน, ใต้, กลาง, กทม. ดูว่าแต่ละภาคมีสัดส่วนประชากรเท่าไหร่ โดยให้ทั้งประเทศ = 100% สมมติ เหนือ 10%, อีสาน 35%, กทม. 10%, กลาง 30% และใต้อีก 15%
  • Step 2 — สุ่มอำเภอ: ในแต่ละจังหวัดเราก็จะสุ่มอำเภอที่จะเอามาเป็นกลุ่มตัวอย่างอีกทีนึง โดยที่มันจะมีตารางตีช่อง grid จากแผนที่เลย จากนั้นก็จะสุ่ม block ที่เราจะไปเดินสัมภาษณ์ และทุก block จะต้องมีโอกาสถูกสุ่มเท่ากัน
  • Step 3 — เลือกบ้าน (Left hand rule skip every 4 houses): สัมภาษณ์บ้านหลังแรก แล้วข้ามหลังที่ 2, 3, 4 แล้วค่อยไปสัมภาษณ์หลังที่ 5 ทำแบบนี้ไปเรื่อยๆ ถ้าเจอแยกให้เลี้ยวซ้ายเสมอ (AKA เหมือนเป็นการทำ Systematic random sampling) ที่ต้องกำหนดให้เลี้ยวซ้ายเพราะมันจะได้ไม่มั่วเวลาเก็บข้อมูล
  • กรณีไม่มีคนอยู่บ้าน: ถ้าหลังที่เราต้องสัมภาษณ์ไม่มีคนอยู่ เราจะทดไว้ก่อน แต่ถ้าไม่เจอเกิน 3 ครั้ง เราก็ต้องไปหาหลังใหม่ ไปหาคนใหม่มาแทนที่ที่มี profile คล้ายๆ กัน
� เราสามารถเอาทั้ง 3–4 วิธีมาใช้ร่วมกันได้ ตัวอย่างเช่น ในการแบ่งภาคเราใช้วิธี Stratified random sampling แต่พอมาถึงระดับหมู่บ้านหรืออำเภอ เราก็ไปใช้วิธี Systematic random sampling
�📝 ในชีวิตจริง ความจริงอันโหดร้าย — ลูกค้ามักจะจิ้มจังหวัดหรืออำเภอที่เล็งไว้อยู่แล้ว ไอที่เราคิดๆ มาหรือทำข้อมูลทางสถิติมามันไม่ได้ใช้ เพราะว่าแต่ละพื้นที่ก็จะมีแบรนด์ที่คนซื้อเยอะ เหมือนเป็นจังหวัดเก่งของแต่ละแบรนด์นั่นแหละ
📝 การทำ Census (สำมะโนประชากร) ก็นับเป็นการทำ Sample รูปแบบหนึ่ง

Non-Probability Sampling — การสุ่มแบบไม่มีความน่าจะเป็น

ไม่ทุกคนมีโอกาสถูกเลือก ง่ายและรวดเร็วกว่า แต่มี Bias สูงกว่ามาก

Bias สูง

Convenience Sampling (การสุ่มแบบสะดวก)

ตัวอย่างที่เจอบ่อยที่สุดคือการทำ survey ใน Google Form ส่งให้เพื่อน, แปะตามกลุ่มต่างๆ sample ที่ได้ไม่สามารถ represent ไปถึง population ได้เลย

ลองนึกภาพ ถ้าคนทำ survey อยู่โรงเรียนชายล้วน เพื่อนใน social media สัดส่วนผู้ชายก็ต้องมากกว่าผู้หญิง นั่นแหละทำให้ survey มี bias

Bias สูงมาก

Snowball Sampling

เริ่มจากหาคนที่เกี่ยวข้องคนแรก แล้วถามว่ามีเพื่อนหรือคนรู้จักที่รู้เรื่องนี้ไหม แล้วถามต่อๆๆๆ ไปเรื่อยๆ

Bias เยอะแน่ๆ เพราะ sample ที่ได้มักคล้ายๆ เหมือนๆ กัน ความคิดเห็นไม่มีความหลากหลาย

⚠️ ทั้ง 2 วิธีนี้เอาไปทำงานจริงไม่ได้เลย ถ้าหากลุ่มตัวอย่างแบบนี้ในการทำงานจริงโดนลูกค้าด่าแน่ ไม่คุ้มเงินที่ลูกค้าให้ และ bias เยอะอีก
📝 สุดท้ายแล้วเราจะเลือกใช้วิธีไหนเพื่อหา sample มันอยู่ที่ objective ด้วย ในบางสถานการณ์ Snowball sampling ก็อาจจะจำเป็นต้องใช้ หรือบางสถานการณ์เราก็ใช้ prop-sampling

Trade-off สำคัญมาก!!

ยิ่ง sample size เราใกล้เคียงกับ population มากเท่าไหร่ ผลลัพธ์ที่เราได้ก็จะแม่นยำมากขึ้นเท่านั้น แต่!!! ในการทำงานจริงๆ มันยากมาก ถ้าเราอยากได้ sample size ที่ใกล้เคียง pop เราก็ต้องแลกมากับเวลาในการเก็บข้อมูลเยอะมากๆ

Trade-off: Time + Budget  VS  Value

CPI = Cost per interview

Garbage in, Garbage out — ถ้า sample ไม่ดี ผลลัพธ์ก็ไม่ดีตามไปด้วย

Sample Size 101

Sample size สำคัญมากๆ ถ้าข้อมูลหรือ sample size ที่เรามีมันถูกต้อง มีคุณภาพ ตัวเลขทางสถิติมันก็จะน่าเชื่อถือ กลับกันถ้า sample size ที่ได้มามันไม่มีคุณภาพ bias เยอะ แน่นอนว่าตัวเลขทางสถิติที่ออกมามันก็ไม่มีคุณภาพตาม

Basic concept: ยิ่ง sample size เยอะเท่าไหร่ มันก็จะยิ่ง represent ไปหา population ได้ดี
N เยอะขึ้น → เข้าใกล้ population มากขึ้น → ผลลัพธ์ที่ได้ดีขึ้น

แล้วเราต้องเก็บเท่าไหร่ถึงจะพอ?

สมมติเรามีตัวอย่าง population = 1,000 | Confidence level = 95% | Margin of error = 10%

Confidence 95% หมายความว่า

ถ้าเราทำการทดลองซ้ำ 100 ครั้ง จะมี 95 ครั้งที่ได้ผลลัพธ์เหมือนกัน

Margin Error 10% หมายความว่า

ผลลัพธ์ที่ได้จะบวกลบ 10% จากผลจริง เช่น ได้ 70% จริงอาจอยู่ระหว่าง 60–80%

ตัวอย่าง Lower Bound & Upper Bound

สมมติทำ survey เรื่อง WFH โดยที่ n = 1,000 สุ่ม sample size ได้ 88 คน ผลสรุปออกมาว่าชอบ WFH 70% ของ 88 คน และไม่ชอบ WFH อีก 30%

Margin error 10%
⇕
60% — 80%
(Lower — Upper bound)
Margin error 5%
⇕
65% — 75%
แม่นยำขึ้น ต้องเก็บข้อมูลเพิ่ม

ยิ่ง Margin error น้อย ก็จะยิ่งทำให้ผลลัพธ์เรา estimate ได้มากขึ้น

กราฟ Margin Error vs. n(sample_size) — ยิ่ง sample size น้อย margin error ก็จะเยอะ

Margin Error | Sample Size | Confidence Level — ความสัมพันธ์ที่ต้องรู้

ช่วงแรกที่เราเก็บ sample size เพิ่มขึ้น margin error มันจะลดลงมาเยอะมาก แบบลดฮวบ แต่พอถึงจุดนึงการที่เราอยากจะลด error เราต้องเพิ่ม sample size เป็นเท่าตัวหรือสองเท่าตัวเลย เหมือน Diminishing Return เลย ทุกครั้งที่เราเพิ่ม sample size ทำให้เราลด error ได้ในอัตราที่ลดลงเรื่อยๆ

Diminishing Return — ยิ่งลด ME จากจุดต่ำๆ ยิ่งต้องเพิ่ม n มากขึ้นเรื่อยๆ ไม่คุ้มค่า

แล้วควรหยุดที่ตรงไหนถึงจะคุ้ม?

ส่วนใหญ่ค่า default จะอยู่ที่ 5% ที่เราจะใช้บ่อยที่สุด เพราะถ้าเก็บมากกว่านี้มันเริ่มไม่คุ้มกับเวลาและเงินที่เสียไปแล้ว ไม่มีกฎตายตัว แต่ 5% เป็นค่าที่คนใช้เยอะที่สุด

📝 5% ใน ME เราเรียกว่า Arbitrary — เป็นค่าที่ไม่มีกฎตายตัว
