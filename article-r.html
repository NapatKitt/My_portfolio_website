R Data Analysis

R Programming 101

28 กุมภาพันธ์ 2026 · อ่านประมาณ 6 นาที

ทำไมต้อง R?

R เป็นภาษาโปรแกรมมิ่งที่ถูกออกแบบมาเพื่องาน Statistical Computing และ Data Analysis โดยเฉพาะ แม้ว่า Python จะได้รับความนิยมมากกว่าในปัจจุบัน แต่ R ยังคงเป็นที่นิยมสูงมากในวงการวิชาการ งานวิจัย และสายงาน Biostatistics เพราะมี packages สำหรับการวิเคราะห์ทางสถิติที่ครบครันมากครับ

โครงสร้างข้อมูลพื้นฐาน

R มีโครงสร้างข้อมูลหลักที่ต้องรู้จัก:

  • Vector: โครงสร้างพื้นฐานที่สุดใน R เก็บข้อมูล 1 มิติที่เป็นชนิดเดียวกัน เช่น c(1, 2, 3, 4) หรือ c("a", "b", "c")
  • Data Frame: โครงสร้างที่คล้าย spreadsheet มีแถวและคอลัมน์ คล้ายกับ DataFrame ของ pandas ใน Python เป็น structure ที่ใช้งานมากที่สุดในงาน Data Analysis
  • List: เก็บข้อมูลหลายชนิดผสมกันได้ในโครงสร้างเดียว แตกต่างจาก Vector ที่ต้องเป็นชนิดเดียวกัน
  • Matrix: Vector 2 มิติ ใช้สำหรับการคำนวณทางคณิตศาสตร์และ Linear Algebra

การจัดการข้อมูลด้วย tidyverse

tidyverse คือชุด packages ที่ทำให้การจัดการและวิเคราะห์ข้อมูลใน R เป็นเรื่องง่าย ออกแบบมาให้ทำงานร่วมกัน มีแนวคิดที่ consistent และอ่านโค้ดได้ง่ายมาก:

  • dplyr: จัดการ Data Frame ด้วย verb ที่ชัดเจน เช่น filter(), select(), mutate(), summarise()
  • tidyr: จัดรูปแบบข้อมูลจาก wide เป็น long หรือกลับกัน ด้วย pivot_longer() และ pivot_wider()
  • readr: อ่านไฟล์ข้อมูลเช่น CSV ได้เร็วและสะดวกกว่า built-in functions ปกติ
  • Pipe operator (|>): ส่งผลลัพธ์จาก step หนึ่งไปยัง step ถัดไป ทำให้โค้ดอ่านง่ายและเขียนได้ลื่นขึ้นมาก

Visualization ด้วย ggplot2

ggplot2 เป็น package สำหรับสร้างกราฟที่สวยงามและยืดหยุ่นมาก อิงตามแนวคิด Grammar of Graphics ที่แบ่งกราฟออกเป็น "layer" ซ้อนกัน:

  • Data: ข้อมูลที่ใช้สร้างกราฟ
  • Aesthetics (aes): mapping ว่าตัวแปรไหน → แกน x, แกน y, สี, ขนาด
  • Geoms: รูปแบบกราฟ เช่น geom_point(), geom_bar(), geom_line(), geom_histogram()
  • Facets: แบ่งกราฟเป็น panel ย่อยตามกลุ่มข้อมูลได้ง่ายมาก
  • Themes: ปรับสไตล์กราฟได้ครบ ตั้งแต่สีพื้นหลัง ฟอนต์ gridlines

💡 แนะนำให้เริ่มต้นด้วย RStudio ซึ่งเป็น IDE ที่ดีที่สุดสำหรับ R และเรียนควบคู่กับ R for Data Science (หนังสือออนไลน์ฟรี) ได้เลยครับ
