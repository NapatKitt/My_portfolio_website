Intro to SQL

28 กุมภาพันธ์ 2026 · อ่านประมาณ 6 นาที

SQL คืออะไร?

SQL (Structured Query Language) คือภาษาที่ใช้สื่อสารกับฐานข้อมูลเชิงสัมพันธ์ (Relational Database) ไม่ว่าจะเป็น MySQL, PostgreSQL, SQLite หรือ SQL Server ก็ใช้ภาษา SQL เป็นหลักทั้งนั้นครับ ถ้าคุณทำงานด้าน Data หรือ Backend การรู้จัก SQL ถือเป็น skill ที่จำเป็นมากๆ

SELECT — ดึงข้อมูล

คำสั่งพื้นฐานที่สุดคือ SELECT ใช้สำหรับดึงข้อมูลจากตาราง:

  • SELECT * FROM users; — ดึงทุกคอลัมน์จากตาราง users
  • SELECT name, email FROM users; — ดึงเฉพาะคอลัมน์ที่ต้องการ
  • SELECT * FROM users WHERE age > 25; — ดึงเฉพาะแถวที่ตรงเงื่อนไข
  • SELECT * FROM users ORDER BY name ASC; — จัดเรียงผลลัพธ์

JOIN — เชื่อมข้อมูลจากหลายตาราง

เมื่อข้อมูลอยู่คนละตาราง เราใช้ JOIN เพื่อรวมข้อมูลเข้าด้วยกัน:

  • INNER JOIN: ดึงเฉพาะแถวที่มีข้อมูลตรงกันในทั้งสองตาราง
  • LEFT JOIN: ดึงแถวทั้งหมดจากตารางซ้าย แม้ไม่มีข้อมูลตรงกันในตารางขวา
  • RIGHT JOIN: ดึงแถวทั้งหมดจากตารางขวา
  • FULL OUTER JOIN: ดึงทุกแถวจากทั้งสองตาราง

Aggregate Functions — สรุปผล

ใช้รวมข้อมูลหลายแถวให้เป็นค่าสรุปเดียว มักใช้คู่กับ GROUP BY:

  • COUNT(*): นับจำนวนแถว
  • SUM(column): รวมค่าในคอลัมน์
  • AVG(column): ค่าเฉลี่ย
  • MAX / MIN: ค่าสูงสุด / ต่ำสุด

ลองฝึกเขียน SQL ด้วยเครื่องมือออนไลน์อย่าง SQLiteOnline.com หรือลง PostgreSQL บนเครื่องตัวเองเพื่อเรียนรู้แบบ hands-on ได้เลยครับ
