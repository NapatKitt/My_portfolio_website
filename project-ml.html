Machine Learning Prediction

Scikit-learn Pandas Python

โมเดลทำนายการเลิกใช้บริการของลูกค้า (Customer Churn Prediction) มุ่งเน้นการวิเคราะห์พฤติกรรมลูกค้าเพื่อช่วยลดอัตราการสูญเสียลูกค้าได้อย่างมีประสิทธิภาพและเตรียมกลยุทธ์รักษาลูกค้าได้ทันเวลา

Key Features

  • High Accuracy Model: อัลกอริทึมมีความแม่นยำสูงถึง 85% ในการคาดการณ์จากข้อมูลย้อนหลัง
  • Data Preprocessing Pipeline: ระบบจัดการข้อมูลสูญหาย และแปลงข้อมูลอัตโนมัติด้วย Pandas
  • Feature Importance Analysis: วิเคราะห์ปัจจัยสำคัญที่มีผลต่อการยกเลิกบริการของลูกค้า
  • Automated Retraining: โมเดลเตรียมความพร้อมในการนำข้อมูลใหม่มาเรียนรู้ซ้ำแบบรายเดือน

Project Detail

กระบวนการเริ่มต้นจากการนำข้อมูลลูกค้ามากกว่า 100,000 รายการมาทำ Data Cleaning ด้วย Pandas เพื่อจัดการค่าอคติ หลังจากนั้นจึงนำอัลกอริทึมของ Scikit-learn ได้แก่ Random Forest และ XGBoost มาเทรนโมเดล ผลลัพธ์ที่ได้ทำให้บริษัทเข้าใจพฤติกรรมลูกค้าที่เปลี่ยนไป และสร้างแคมเปญส่งเสริมการขายได้ตรงกลุ่มเป้าหมายขึ้น ส่งผลให้ Churn Rate ลดลง 15% ภายในไตรมาสเดียว
